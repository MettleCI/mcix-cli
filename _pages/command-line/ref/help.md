## help

![help](img/help.svg "help")

The `help` command is a special MCIX shell command which provides assistance on using the MCIX command 
shell or its commands, as well as the CLI version number.

#### Parameters

| Supplied              | Output |
| :-------              | :----- |
| No parameters         | Lists available namespaces |
| `namespace`           | Lists commands available within the specified namespace |
| `namespace` `command` | Produces the usage description for the specified command |

<details markdown="1">
  <summary>Example</summary>
```bash
$> mcix help
MettleCI Command Line (build 1.0-123)
(C) 2018-2026 Data Migrators Pty Ltd
Usage: [namespace] [command] [command options]
  Namespaces:
    overlay
    datastage
    asset-analysis
    unit-test
    system

$> mcix help datastage
MettleCI Command Line (build 1.0-123)
(C) 2018-2026 Data Migrators Pty Ltd
Usage: datastage [command] [command options]
  Commands:
    compile        Compile DataStage assets that don't have up to date binaries
    import         Incrementally import DataStage assets into a CP4D project
    export         Export all DataStage assets from a CP4D project

$> mcix help datastage export
MettleCI Command Line (build 1.0-123)
(C) 2018-2026 Data Migrators Pty Ltd
Usage: datastage export [options]
  Options:
  * -api-key
      CP4D/CP4DaaS API key
  * -export-path
      Path to save the export
    -include-binaries
      Export binaries generated by compilation
      Default: false
    -project
      Name of project (one of -project, -project-id is required)
    -project-id
      Id of project (one of -project, -project-id is required)
  * -url
      Base url of CP4D/CP4DaaS
  * -user
      CP4D/CP4DaaS username
```
</details>
